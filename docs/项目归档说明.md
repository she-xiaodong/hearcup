# 项目归档说明（快照）

> 归档时间：2026-08-30 · 版本：**v2.0.0**（音视频通话接入）
> 用途：项目阶段性冻结。接手人（老板本人或 AI）读这一份即可快速恢复上下文，知道「做到哪了、下一步干什么、有哪些坑」。

## 一、项目一句话定位

**Hearcup（一杯心晴）**：即时语音/视频倾诉平台。用户选倾听者 → 点击呼叫 → 真机音视频接通 → 按分钟扣费 → 评价。
微信小程序（用户端 + 倾听者端合并）+ Go 后端（零外部框架）+ 零构建管理后台。

---

## 三、关键架构决策（别推翻，都是踩过坑定下来的）

| 决策 | 结论 | 原因 |
|---|---|---|
| 后端框架 | 标准库 `net/http`，弃 Gin/GORM/Redis/Casbin | Go 代理不可达，需离线可编译；接口结构严格对齐需求，日后可无痛换回 |
| 离线触达通道 | 腾讯云 IM + TUICallKit | 老板拍板（弃自研 WebSocket+订阅消息） |
| 倾听者端形态 | 同一小程序内「倾听者工作台」 | 复用现有 appid |
| TUICallKit 集成方式 | **vendor 拷贝** `miniprogram/TUICallKit/`（删 debug/） | 与官方 demo 一致 |
| TUICallKit 引擎 | Lite 引擎（`@trtc/call-engine-lite-wx@5.0.6`，Pure-JS 无 WASM） | 无需拷贝 wasm |
| IM 身份 | 统一单一 `hearcup_{uid}` | 避免同人双身份串线 |
| UserSig 算法 | zlib 压缩 + 腾讯私有转义（`+→* /→- =→_`） | 此前用明文 JSON base64 导致 70003 非法签名 |
| 设备 VoIP 授权 | **不适用**（`wx.requestDeviceVoIP` 是硬件专用） | 纯软件无硬件；最强触达 = IM 离线推送 + 订阅消息 |

## 四、关键坑（务必记住）

1. **主包体积**：`@tencentcloud/lite-chat` 的 `miniprogram:"."` 会把 5.6M 冗余变体带进主包。构建 npm 后必须**手动拷贝 `basic.js` 并删除 `index.js`**（见 README「音视频通话接入」），否则主包超 2M 限制。
2. **订阅消息授权时机**：首次进入**不**批量申请，在「上线接单」关键动作时再弹；拒绝后再次调用可能不弹，需引导手动进设置页。
3. **Android 10 以下**：无锁屏来电弹窗，仅微信通知提醒，已做低版本提示。
4. **微信开发者工具不支持** live-pusher/live-player，音视频必须**真机**测试，且需**企业主体**小程序。
5. **生产域名死规定 = `shanlianba.com`**：现网唯一域名（支付回调、小程序 baseUrl、nginx 反代均用它）。`51dzzd.com`、`51xjhz.com` 已永久废弃，任何代码/配置/文档不得再使用。
